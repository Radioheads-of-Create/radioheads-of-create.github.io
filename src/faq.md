# Airwaves FAQ

### What is Airwaves?
Airwaves is a realisticish radio mod for Create and Minecraft. It allows players to broadcast radio in a world, and even to other dimensions. Airwaves offers a ton of new content for Create. This mod is also a full remake of the orignal mod, Create: Airwaves, that has been fully deleted due to many reasons.

### What happened with the old mod? 
The old mod was deleted by it's "author," as the person who "made it" told me they got "tired" of it and deleted it. 
Other unoffical reasons is that it was vibecoded (it was) and they ran out of tokens and deleted it.

### Is this mod vibecoded?
**No**, due to the license, using generative-AI is strictly prohibited. See [CONTRIBUTING.md](https://github.com/Radioheads-of-Create/Airwaves/?tab=contributing-ov-file). 

### Will my world with the old mod still work?
**No**, this mod is a **full rewrite** of the mod, including many drastic changes. Worlds with the old mod will **not** work.

### When will this mod be released?
There is no current ETA of a first release. There is a lot to be done for the mod. 
If you wish to be a contributer, feel free to make a pull request here: [Radioheads-of-Create/Airwaves](https://github.com/Radioheads-of-Create/Airwaves/)

### What is different with this mod and the old one?
There are a **lot** of changes. Circuit boards will be simulated instead of hardcoded, more addon and user friendly, and more!

### Where can I get dev builds?
There is currently one way to obtain dev builds, and that is on the (Radioheads of Create)[https://discord.gg/rp6fK7F92Z] Discord server. 
GitHub releases will be setup soon so you do not need to join the Discord server (all progress updates, announcements, and more are there, including all dev builds.)

### Could I help translate the project?
**Yes!** There is a Crowdin translaton project that you can help out on [here](https://crowdin.com/project/create-airwaves)

### Is (insert mod here) supported?
Airwaves will have full addon support and be fully documented. We will have some integrations with basic mods.
Some current integrated mods are:
- Sable (Aeronautics)
- Computer Craft: Tweaked
- The Factory Must Grow (Community Edition for some recipe compatability)
- KubeJS
- Curios
- Analog Audio (For playing music on air)
